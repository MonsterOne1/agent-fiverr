# Agent Fiverr

Research and planning repo for an agent-native Fiverr-style marketplace.

Current scope:

- Analyze Fiverr service categories and agent automation feasibility.
- Define execution strategy, workspace structure, and acceptance criteria.
- Plan API/provider requirements per task type before implementation.

Not started yet:

- No product code.
- No agent workspace implementation.
- No API keys or provider credentials.

See [docs/agent-fiverr-plan.md](docs/agent-fiverr-plan.md).
